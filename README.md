# 🕹️ NFT Stake Game on Solana

A **Solana NFT staking game** built with **Anchor**, where players can mint, stake, and compete for rewards.  

---

## ⚡ Features

- **🎨 NFT Minting** – Mint unique NFTs with metadata & master edition  
- **💎 NFT Staking** – Stake NFTs and pay entry fee in SOL  
- **📊 Score Tracking** – Update and track player scores  
- **🏆 Reward Distribution** – Top players earn the prize pool, owner gets a share  
- **⏳ Time-Locked Pool** – Rewards are locked for a fixed duration  

---

## 🛠️ Tech Stack

- **Solana & Anchor** – Smart contracts  
- **Rust** – Program logic  
- **SPL Token / Metadata** – NFT minting & management  
- **HashMap & Vec** – Score & reward management
